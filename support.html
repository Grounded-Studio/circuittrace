Yes, fully. All 500+ puzzles, 7 modes, and the Puzzle Editor work offline. Internet is only needed for: Daily Challenge sync (optional), Google Play Games cloud save (opt-in), and ads loading (if you haven't bought Remove Ads).
Android 8.0 (Oreo) or newer. The game is lightweight (~65 MB) and runs smoothly even on older devices from 2018+.
In the Circuit Trace main campaign, levels unlock as you solve them. In Classic / Diodes / Portals / Arcade modes, all 100 levels are available from the start — no gatekeeping. Expert preview is instantly accessible.
Open the Creator hub from the main menu, tap "Make a Puzzle", choose a grid size (5×5 to 8×8), place colored pairs and optional diodes, then tap CHECK to validate. Once valid, tap SHARE to generate a short code like CT-NHH06-8CMY4-AG2DS. Share that with friends via WhatsApp, Discord, or any messaging app.
Codes start with CT- followed by 6 blocks of 5 characters separated by dashes. Example: CT-NHH06-8CMY4-AG2DS-C5DJ0-00000-00009. The code encodes grid size, pair positions, diode positions and directions, plus a checksum for typo detection. All 100% offline — no server needed.
Open the Creator hub, tap "Play Shared Code", paste or type the code, tap Play. The puzzle loads instantly. No account, no login — just the code is enough.
