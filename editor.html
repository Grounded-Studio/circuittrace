How it works

Four taps to a shared puzzle.

No account needed. No signup. Just design and share.

1

Pick a size

Choose a grid: 5×5 for quick, 6×6 for standard, 7×7 for challenging, or 8×8 for serious brain-stretching.

2

Place dots and diodes

Tap a color, then two cells to make a pair. Add up to 5 colored pairs. Optionally drop one-way diodes with per-color locks.

3

Validate

Hit CHECK. The editor instantly tests if your puzzle has a solution. If pairs block each other, it tells you which ones.

4

Share the code

Hit SHARE. You get a short code like CT-NHH06-8CMY4-AG2DS. Send via WhatsApp, Discord, SMS — anywhere.

Technical

About the code format

Short, memorable, and OCR-friendly.

CT-NHH06-8CMY4-AG2DS-C5DJ0-00000-00009

Each code uses Crockford Base32 encoding — the same format used by UUIDs and other short identifier systems. We picked it because:

  • OCR-safe: no ambiguous characters like 0/O or 1/I/L
  • Easy to type: 30 characters total, grouped in blocks of 5 with dashes
  • Checksum built in: typos get detected automatically
  • Compact: encodes grid size, up to 5 pair positions, up to 5 diode positions + directions, and reserved space for future features

The code is completely offline — no server needed. The whole puzzle state lives in those 30 characters.
