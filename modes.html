Game Modes

Seven ways to play.

Each mode twists the same core idea — connect every pair — into a completely different experience.

The main campaign

Circuit Trace

The hero mode. 100 handcrafted levels across 10 sectors — each sector introduces one new mechanic.

  • Sector 1-2: Basic flow puzzles — learn the core mechanic
  • Sector 3-4: Introduction of stars (bonus goals) and fill-every-cell rule
  • Sector 5-6: Checkpoints added — paths must pass through specific cells
  • Sector 7-8: One-way diodes introduced — directional flow constraints
  • Sector 9-10: Portals and expert-level combinations of all mechanics
💡 Progress unlocks mechanics gradually. Never overwhelming.
●
The calming mode

Classic

Pure Flow-style puzzles. No mechanics. No surprises. Just you, colored pairs, and connecting them.

  • ✓ 100 handcrafted levels
  • ✓ No special mechanics
  • ✓ Perfect for winding down before bed
  • ✓ Great starting point for new flow-puzzle players
The logic mode

Diodes ▶

One-way arrows add a logical twist. Each diode forces the path to flow in a specific direction. Think before you draw.

  • ✓ 100 handcrafted levels
  • ✓ Directional constraints via diodes
  • ✓ Great for puzzle fans who like deductive logic
  • ✓ Harder than Classic — satisfying when you crack them
▶ ▼ ◀ ▲
◉
The spatial puzzle

Portals ◉

Linked portal pairs teleport your path across the grid. Think of it as two boards at once connected through colorful warps.

  • ✓ 100 handcrafted levels
  • ✓ Portal pairs connect distant cells
  • ✓ Spatial reasoning challenge
  • ✓ Teaches you to visualize non-linear paths
The mastery mode

Arcade ★

The gauntlet. All mechanics stacked — stars, diodes, checkpoints, portals, fill-every-cell. 100 escalating puzzles for players who've mastered the basics.

  • ✓ 100 handcrafted levels
  • ✓ All mechanics combined
  • ✓ Progressive escalation
  • ✓ For the pros — not for the faint of heart
★ ▶ ⊙ ◉
∞
The infinite mode

Endless ∞

Procedurally-generated puzzles that never end. Pick a board size from 5×5 to 9×9 and chain unlimited solves.

  • ✓ Infinite puzzles
  • ✓ 5 difficulty levels (5×5, 6×6, 7×7, 8×8, 9×9)
  • ✓ Streak tracking
  • ✓ Change difficulty on-the-fly without losing streak
The taste test

Expert preview ⚡

A random sector 8-9 puzzle on tap. Taste of late-campaign difficulty without needing to unlock it. Great for a quick brain-stretch.

  • ✓ Instant access to pro-level puzzles
  • ✓ Random seeding — different puzzle every tap
  • ✓ Doesn't affect campaign progress
  • ✓ Perfect for 2-minute brain workouts
