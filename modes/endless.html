The infinite mode

Endless: it never runs out

Pick a difficulty and keep going. Every round is a freshly generated puzzle.

How it works

Endless has no levels to work through. You pick one of seven difficulties and the game builds a new puzzle for you each round.

It is the mode for when you have finished a pack, or just want one more puzzle at exactly the size you like. Short on time? Casual takes moments. Want a proper challenge? Try Legend.

  • ✓ Unlimited generated puzzles
  • ✓ 7 difficulty levels
  • ✓ Boards from 5×5 to 8×8
  • ✓ 3 to 7 colour pairs

Picking a difficulty

  • New to the game? Start on Casual or Relaxed and move up when the boards feel easy.
  • A step up in colours on the same board size makes a real difference, so try each one before jumping to a bigger grid.
  • Legend is an 8×8 board with 7 colours. Give yourself a moment to read it before drawing.
